# ApiProjekt

Detta repository innehåller en grundversion av ett API byggt i C#/.NET. Projektet är en basstruktur för att öva på webbtjänster, konfiguration och miljöhantering.

## 🛠 Funktioner
- Konfiguration via `appsettings.json`  
- REST API med `Program.cs` som startpunkt  
- Projektfil (`ApiProjekt.csproj`) för beroenden och struktur  

## 🚀 Kom igång
```bash
git clone https://github.com/Daliazan/ApiProjekt.git
cd ApiProjekt
dotnet restore
dotnet run
